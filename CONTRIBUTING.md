# Contribuindo

1. Abra uma issue antes de mudanças grandes.
2. Mantenha mudanças pequenas e focadas.
3. Execute `npm test` e `npm run check` antes de abrir um pull request.
4. Não inclua chaves, arquivos `.env`, cache ou dados coletados em commits.

Ao alterar comportamento de busca, cache, pontuação ou custos, atualize o README e inclua testes.
