# Segurança

Nunca reporte vulnerabilidades, chaves de API ou dados pessoais em issues públicas. Envie um relato privado ao mantenedor do repositório com passos de reprodução e impacto.

Se uma chave for exposta, revogue-a no Google Cloud Console, gere outra e aplique restrições de API e de aplicação/IP antes de reutilizá-la.
